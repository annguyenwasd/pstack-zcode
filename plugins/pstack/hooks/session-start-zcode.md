On zcode, load pstack skills as `/pstack:<name>`; the bare `/<name>` form also resolves. The plugin's agents keep the prefix (`pstack:poteto-agent`, `pstack:comment-sicko`). The skills speak zcode tool names, paths, and models natively, so no tool mapping is needed. pstack ships no default role models beyond the tiers in its models.json. A skill that dispatches on role models takes them from the user's saved pstack model choices. The plugin hook reads them from the zcode sheet, `~/.zcode/rules/pstack-models.md`, checks them, and adds them to the end of this block. Do not read the sheet; use the role lines below.
